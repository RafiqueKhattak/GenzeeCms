# Google Search Console — manual indexing checklist

Generated 1 Aug 2026, right after the genzeetools → GenzeeCms cutover, to help
Google recrawl the new site faster than its normal crawl schedule. GSC's manual
"Request Indexing" tool has a small daily quota per property (roughly 10-12
URLs/day) — this checklist spreads all 137 sitemap URLs across days so none get
wasted on quota errors.

**How to use:** Search Console → URL Inspection (top search bar) → paste one URL
→ wait for the inspection result → click **Request Indexing**. One group per day.
